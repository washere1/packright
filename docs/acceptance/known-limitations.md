# Known limitations and non-guarantees

- Validation is deterministic, conservative, and box-based.
- Detailed meshes are visual context only; mesh geometry is not collision-certified.
- The center of mass is a mass-at-box-center heuristic, not a stability guarantee.
- Search exhaustion is not proof that no arrangement exists.
- Browser preview capture requires the browser; cuboid fallback remains available.
- There are no accounts, cloud synchronization, airline certification, irregular-contact physics, or native mobile client.
